# Akapulu Labs agent plugins

Public skills for coding agents building on [Akapulu Labs](https://akapulu.com) (live avatar conversations and scripted clips).

## For humans

Paste this into Cursor, Claude Code, or Codex:

```text
Set up Akapulu Labs for me: fetch https://raw.githubusercontent.com/william-akapulu/akapulu-plugins/main/agent-setup.md and follow it.
```

That installs the `akapulu` skill and the [docs MCP](https://docs.akapulu.com/mcp). You still create an API key in the dashboard if you are embedding a conversation in your app. Hosted links do not need a key.

## For agents

`agent-setup.md` is the installer. Skills live under `skills/`.
